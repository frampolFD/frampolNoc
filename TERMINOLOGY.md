# TERMINOLOGY.md

Use these terms consistently.

Customer — Frampol client.

City / Town — Geographic city or town belonging to a customer.

Suburb / Area — Optional geographic subdivision within a city.

Branch — Physical customer location.

WAN Link — Internet/WAN circuit being monitored.

ISP — Provider of a WAN Link.

Circuit Capacity — Contracted/expected link capacity, e.g. 100 Mbps.

ICMP Target IP — IP address used for ping monitoring.

SNMP Target IP — IP address used to reach the SNMP target.

SNMP Interface — The discovered interface selected for monitoring.

ifIndex — SNMP interface index.

RX — Received/download traffic.

TX — Transmitted/upload traffic.

Total Throughput — RX + TX.

Consumption — Amount of data transferred over a period.

Utilisation — Throughput as a percentage of circuit capacity.

Engineer Notes — Operational notes attached to a WAN Link.

Branch WAN Overview — Screen showing all WAN Links at one Branch.

WAN Link Details — Deep troubleshooting screen for one WAN Link.

Monitoring Disabled — WAN exists but technical monitoring is not active.
